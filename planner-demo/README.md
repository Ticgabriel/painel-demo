# Mesa do planejador — demonstração

Todos os registros, nomes, documentos, valores, datas e relatos foram gerados artificialmente. Não importar bases reais neste ambiente de demonstração.

- 48 atendimentos; OSs individuais e agrupadas.
- 3 vendedores, 12 clientes fictícios, carteiras variadas.
- Fases, pedidos múltiplos, prazos, confirmações vazias/anteriores, arquivados e quarentena.
- Rascunho exclusivo desta demonstração: não reutiliza o identificador do controle de trabalho.
- Abrir `index.html` no navegador. Dados editados ficam no armazenamento local; Salvar backup exporta JSON.
- O gerencial e o comercial estão na raiz do mesmo repositório. A integração de atualizações ainda será especificada.

Código fonte em `src/`. Não contém as planilhas ou os JSONs de trabalho.
